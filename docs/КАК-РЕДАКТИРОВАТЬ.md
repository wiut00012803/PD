# Как редактировать сайт Pravoe Delo

Почти всё на сайте меняется в редакторе **Pages CMS**: тексты, контакты, фото, услуги, кейсы, отзывы и вопросы. Программист для этого не нужен. Нельзя поменять только фирменный стиль: цвета, шрифты, расположение блоков, логотип, картинку для соцсетей и страницу 404 (она только на русском).

## Вход

1. Откройте **https://app.pagescms.org**.
2. Войдите по ссылке из письма-приглашения. При следующих входах введите свой email — придёт новая ссылка для входа. Если у вас есть аккаунт GitHub, можно войти через него.
3. Выберите проект **wiut00012803 / PD**.

Слева — разделы сайта: «Контакты и ссылки», «Главная», «Услуги», «Кейсы», «Команда», «Отзывы», «FAQ», «Страница консультации», «Подписи интерфейса». В разделе «Media» хранятся все загруженные фото.

## Как устроены поля

- **Три языка.**
  - У переводимых текстов три поля: **RU · Русский**, **UZ · Oʻzbekcha**, **EN · English**.
  - Русское поле обязательно. Исключение — необязательные поля: «Подзаголовок», «Второй абзац», «Полная биография» и подобные их можно оставить пустыми.
  - Если узбекское или английское поле пустое, на этой версии сайта покажется русский текст. Если вы заполнили перевод, заполните и русский вариант.
  - Телефон, email, мессенджеры, ссылки, «Адрес для карты» и названия клиентов вводятся один раз: они общие для всех языков.
- **Списки** (юристы, отзывы, услуги, вопросы и т. д.):
  - элементы свёрнуты, нажмите на элемент, чтобы открыть;
  - «Add» / «Добавить» — новый элемент;
  - корзина — удалить элемент;
  - перетаскивание — поменять порядок, на сайте порядок такой же;
  - у списков есть пределы, например «Цифры» — от 2 до 8.

  **Первым в списке «Юристы» ставьте основателя бюро**: для поисковиков сайт указывает первого юриста основателем.
- **«Показывать на сайте»** — переключатель у большинства секций. Его нет у первых экранов, «Контактов и ссылок» и «Подписей интерфейса».
  - Выключенная секция и её пункт в меню исчезают с сайта, но текст сохраняется.
  - Обязательные поля скрытой секции всё равно должны быть заполнены.
  - «Кейсы» и «Отзывы» скрываются и сами, если в списке нет ни одного элемента.
- **«Сколько кейсов видно сразу» / «Сколько отзывов видно сразу».** Остальные карточки откроются кнопкой «Показать ещё». Текст этой кнопки меняется в «Подписи интерфейса → Кнопки».
- **Фото.** Нажмите на поле фото → «Upload» → выберите файл с компьютера или телефона. Сайт сам уменьшит и сожмёт фото.
  - Форматы: JPG, PNG, WebP, AVIF. Фото с iPhone в формате **HEIC** не подойдут — сохраните их как JPG.
  - Юрист — вертикальное фото, лицо в верхней трети кадра. Без фото будет аккуратная заглушка.
  - «О нас» — горизонтальное или квадратное фото, от 1200 px по ширине.
  - Логотипы клиентов — PNG или WebP на прозрачном фоне.
  - **Не удаляйте из «Media» фото, которые стоят на сайте**, — публикация остановится с ошибкой «файл не найден в медиатеке».
- **Стаж** считается сам из поля «Год начала адвокатской практики» (раздел «Контакты и ссылки»). В любом поле с тремя языками можно написать:
  - `{years}` — подставится число лет;
  - `{yearsWord}` — слово «лет / год / года», по-узбекски «yil», по-английски «year / years».

  Пример: `{years} {yearsWord} защищаем бизнес и людей`. Число обновляется само раз в месяц. Другие слова в фигурных скобках использовать нельзя.
- **Переносы строк и абзацы.**
  - В текстах (ответы, отзывы, описания) Enter начинает новую строку, а пустая строка — новый абзац.
  - В заголовках «Первый экран → Заголовок» и «О нас → Заголовок» Enter делит заголовок на строки на компьютере; на телефоне строки переносятся сами.
- **Длина текста ограничена**, чтобы не ломать вёрстку. Если текст перестал печататься, достигнут лимит. Если поле подсвечено красным или «Save» не проходит, исправьте его по подсказке под полем.

## Сохранение и публикация

1. Нажмите **Save** (Сохранить).
2. Через **2–4 минуты** изменения появятся на сайте. Если не видно — обновите страницу с очисткой кэша: **Ctrl+F5**, на телефоне потяните страницу вниз.

Перед публикацией сайт сам всё проверяет:
- заполнены ли обязательные поля;
- правильный ли формат телефона и ссылок;
- не слишком ли длинные тексты;
- загружены ли фото и открываются ли они.

**Если что-то не так, сайт не ломается** — на нём остаётся предыдущая версия.

## Если изменения не появились через 5 минут

1. Откройте **https://github.com/wiut00012803/PD/actions**. Входить в GitHub не нужно, пока репозиторий открытый.
2. Нажмите на верхний, самый свежий запуск — его название начинается с «Публикация:». Запуск «Публикация: ежемесячное обновление» 1-го числа — это автоматическое обновление стажа, на него внимания не обращайте.
3. Посмотрите на значок запуска:
   - ✅ **зелёная галочка** — всё опубликовано, обновите страницу сайта с очисткой кэша;
   - 🟡 **жёлтый кружок** — публикация ещё идёт. Если вы сохраняли несколько раз подряд, публикации идут по очереди, подождите;
   - ❌ **красный крестик** — под схемой запуска есть отчёт **«Изменения НЕ опубликованы»** с таблицей, например:

     | Где | Что не так |
     | --- | --- |
     | Контакты и ссылки → Телефон | Телефон в формате +998 90 123-45-67 |
     | Команда → Юристы → Юрист №2 → Имя → RU · Русский | поле не заполнено |

     Исправьте эти поля в Pages CMS и снова нажмите **Save**. Если вместо таблицы написано «техническая ошибка», это не ваша ошибка: отправьте ссылку на эту страницу разработчику.

И при зелёной галочке, и при красном крестике в отчёте может быть таблица **«Можно улучшить»**. Это не ошибки, а напоминания: где остались временные данные (заглушки) и каких переводов не хватает.

## Как вернуть предыдущую версию

Каждое сохранение запоминается. Проще всего — написать разработчику, какой раздел и примерно когда вы меняли: он вернёт нужную версию за минуту.

Если у вас есть доступ к GitHub (нужен вход):
1. Откройте файл раздела, например https://github.com/wiut00012803/PD/blob/main/src/content/team.yaml.
2. Нажмите **History** — откроется список сохранений с датами.
3. Откройте файл в нужной версии и скопируйте весь текст кнопкой **Copy raw file**.
4. Вернитесь к текущей версии, нажмите карандаш (**Edit this file**), замените весь текст скопированным и нажмите **Commit changes** в ветку `main`.
5. Через 2–4 минуты сайт обновится.

Удалённые фото так не вернутся — их нужно загрузить заново.

## Что менять нельзя (и не нужно)

Цвета, шрифты, расположение блоков и логотип — это фирменный стиль. Он не редактируется в CMS, чтобы сайт всегда выглядел аккуратно. Для таких изменений нужен разработчик.
