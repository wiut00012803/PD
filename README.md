# Pravoe Delo — сайт адвокатского бюро

Статический сайт на [Astro](https://astro.build) на трёх языках (RU / UZ / EN) со светлой и тёмной темой. Публикуется на GitHub Pages. Контент редактирует заказчик через [Pages CMS](https://pagescms.org) — инструкция для него в [docs/КАК-РЕДАКТИРОВАТЬ.md](docs/КАК-РЕДАКТИРОВАТЬ.md).

## Команды

| Команда | Что делает |
| --- | --- |
| `npm install` | установка зависимостей (Node 22.18+) |
| `npm run dev` | локальный сервер: http://localhost:4321/PD/ |
| `npm run check:content` | проверка всех файлов контента, отчёт на русском |
| `npm run build` | проверка контента + сборка в `dist/` |
| `npm run preview` | просмотр собранного сайта |
| `npm run cms:generate` | пересобрать `.pages.yml` из схемы контента |
| `npm run icons:generate` | пересобрать `src/icons/icons.ts` из Lucide и Simple Icons |
| `npm run shots -- --w=1440,390 --theme=dark,light --lang=ru --page=home` | скриншоты через Playwright (нужен `npx playwright install chromium` и запущенный `npm run dev`) |

## Как устроено

- `src/content/*.yaml` — весь контент сайта. Каждый текст хранится как `{ ru, uz, en }`; если `uz` или `en` пусты, показывается `ru`.
- `src/content/schema.ts` — единственное описание структуры контента (Zod 4): обязательные поля, форматы, лимиты длины и количества, русские подписи полей.

  Из этой схемы получаются:
  - проверка перед сборкой и при сборке (`src/content/validate.ts`, `scripts/check-content.ts`), с русскими сообщениями и предупреждениями о заглушках и непереведённых полях;
  - формы Pages CMS: файл `.pages.yml` генерируется командой `npm run cms:generate`, руками его не правят.

  После изменения схемы: обновить YAML, затем выполнить `npm run cms:generate`.
- `src/assets/uploads/` — фото и логотипы клиентов. Сюда же их загружает Pages CMS. В YAML путь хранится как `/uploads/<файл>`, сайт ищет файл по имени.
- `src/lib/` — загрузка контента, i18n (`tr`, ссылки на языковые версии), типографика (неразрывные пробелы в числах, перед тире и после коротких слов), ссылки на мессенджеры.
- `src/views/` — страницы «Главная» и «Консультация». `src/pages/` — маршруты:
  - `/` и `/consultation/` — русский;
  - `/uz/…`, `/en/…` — другие языки.
- `src/styles/tokens.css` — токены из Figma (`Color · Light` / `Color · Dark`, отступы, радиусы, шрифтовая шкала). Тема переключается атрибутом `data-theme` на `<html>`: по умолчанию берётся из настроек системы, выбор пользователя запоминается.
- Переходы между страницами без перезагрузки — Astro `ClientRouter` (View Transitions).
- Свечение за курсором — `src/scripts/glow.ts`:
  - один источник на странице;
  - плавное следование за курсором;
  - на сенсорных экранах медленно плавает;
  - при `prefers-reduced-motion` неподвижно.
- `tools/figma-bridge/` — локальный мост к Figma для выгрузки логотипа и сверки макетов (в сайт не входит).

## Публикация

`.github/workflows/deploy.yml` запускается:
- на каждый коммит в `main`;
- вручную;
- раз в месяц, чтобы обновлялся стаж.

Порядок шагов: проверка контента → сборка → публикация на GitHub Pages. Если проверка не прошла, публикация не выполняется, а в Summary запуска появляется таблица «Где / Что не так».

Нужная настройка репозитория: **Settings → Pages → Source: GitHub Actions**.

### Свой домен

1. В `astro.config.mjs` (или через переменные окружения сборки) задать `SITE_URL=https://домен` и `SITE_BASE=/`.
2. Подключить домен в Settings → Pages.
3. Обновить адрес sitemap в `public/robots.txt`.
