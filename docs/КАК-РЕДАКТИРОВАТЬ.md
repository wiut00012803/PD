# Как редактировать сайт Pravoe Delo

Весь текст, контакты, фото, услуги, кейсы, отзывы и вопросы на сайте меняются в редакторе **Pages CMS**. Программист для этого не нужен.

## Вход

1. Откройте **https://app.pagescms.org**.
2. Войдите по ссылке из письма-приглашения (или через GitHub, если у вас есть аккаунт).
3. Выберите проект **PD**.

Слева — разделы сайта: «Контакты и ссылки», «Главная», «Услуги», «Кейсы», «Команда», «Отзывы», «FAQ», «Страница консультации», «Подписи интерфейса».

## Как устроены поля

- **Три языка.** У каждого текста три поля: **RU · Русский**, **UZ · Oʻzbekcha**, **EN · English**. Русский обязателен. Если узбекское или английское поле пустое, на этой версии сайта покажется русский текст.
- **Списки** (юристы, отзывы, услуги, вопросы и т. д.):
  - «Add» / «Добавить» — новый элемент;
  - корзина — удалить элемент;
  - перетаскивание — поменять порядок.

  Порядок в редакторе — это порядок на сайте.
- **«Показывать на сайте»** — переключатель у каждой секции. Выключите, и секция исчезнет с сайта, но её текст сохранится.
- **«Сколько видно сразу»** (кейсы, отзывы). Остальные карточки откроются кнопкой «Показать ещё».
- **Фото.** Нажмите на поле фото → «Upload» → выберите файл с компьютера или телефона (JPG, PNG, WebP). Сайт сам уменьшит и сожмёт фото. Хорошие размеры:
  - юрист — вертикальное фото, лицо в верхней трети кадра;
  - «О нас» — горизонтальное или квадратное, от 1200 px по ширине.
- **Стаж** считается сам из поля «Год начала адвокатской практики». В любом тексте можно написать:
  - `{years}` — подставится число лет;
  - `{yearsWord}` — слово «лет / год / года».

  Пример: `{years} {yearsWord} защищаем бизнес и людей`.
- **Перенос строки (Enter)** в заголовке сохраняется на компьютере. На телефоне строки переносятся сами.

## Сохранение и публикация

1. Нажмите **Save** (Сохранить).
2. Через **1–2 минуты** изменения появятся на сайте. Если не видно — обновите страницу с очисткой кэша (**Ctrl+F5**, на телефоне — потяните страницу вниз).

Перед публикацией сайт сам проверяет всё, что вы ввели: заполнены ли обязательные поля, правильный ли формат телефона и ссылок, не слишком ли длинные заголовки. **Если что-то не так, сайт не ломается** — на нём остаётся предыдущая версия.

## Если изменения не появились через 3 минуты

1. Откройте **https://github.com/wiut00012803/PD/actions** — входить в GitHub не нужно.
2. Нажмите на верхний запуск — он называется «Публикация: Update src/content/…».
3. Значок запуска:
   - ✅ **зелёная галочка** — всё опубликовано, обновите страницу сайта с очисткой кэша;
   - ❌ **красный крестик** — внизу страницы запуска есть таблица **«Изменения НЕ опубликованы»** с точным местом и причиной, например:
     > Команда → Юристы → Юрист №2 «…» → Имя → RU · Русский: поле не заполнено
4. Исправьте это поле в Pages CMS и снова нажмите **Save**.

В том же отчёте есть таблица **«Можно улучшить»**. Это не ошибки, а напоминания: где остались временные данные (заглушки) и каких переводов не хватает.

## Как вернуть предыдущую версию

Каждое сохранение запоминается. Если что-то пошло не так, напишите разработчику: любую версию можно вернуть за минуту. Если вы работаете в GitHub сами:

1. Откройте файл раздела в репозитории, например `src/content/team.yaml`.
2. Нажмите **History** и выберите нужную версию.

## Что менять нельзя (и не нужно)

Цвета, шрифты, расположение блоков и логотип — это фирменный стиль. Он не редактируется в CMS, чтобы сайт всегда выглядел аккуратно. Для таких изменений нужен разработчик.
